1-Command Router Installation

Pick your operating system below to SSH into your AW1000 router and install in under 15 seconds.

Windows 10 / 11 (PowerShell or Windows Terminal)

1. Connect your PC to the AW1000 Wi-Fi or LAN cable, open PowerShell, and log in:

ssh root@192.168.1.1

2. Once logged into the router, paste this 1-command installer:

nslookup github.com >/dev/null 2>&1 || echo "nameserver 1.1.1.1" > /tmp/resolv.conf.auto; curl -fsSL https://github.com/sky12388/aw1000-control/releases/download/v1.0.14/aw1000-control-router-v1.0.14.tar.gz -o /tmp/aw1000-control-router-v1.0.14.tar.gz && curl -fsSL https://github.com/sky12388/aw1000-control/releases/download/v1.0.14/install.sh -o /tmp/install.sh && sh /tmp/install.sh /tmp/aw1000-control-router-v1.0.14.tar.gz

Or install via OpenWrt opkg:

nslookup github.com >/dev/null 2>&1 || echo "nameserver 1.1.1.1" > /tmp/resolv.conf.auto; curl -fsSL https://github.com/sky12388/aw1000-control/releases/download/v1.0.14/aw1000-control_1.0.14_all.ipk -o /tmp/aw1000-control_1.0.14_all.ipk && opkg install /tmp/aw1000-control_1.0.14_all.ipk

Optional — install the RGB Ultra LuCI Theme (Dark/Light Mode + Startup A–Z Sort & Search):

nslookup github.com >/dev/null 2>&1 || echo "nameserver 1.1.1.1" > /tmp/resolv.conf.auto; curl -fsSL https://github.com/sky12388/aw1000-control/releases/download/v1.0.14/luci-theme-rgb-ultra_1.0.0_all.ipk -o /tmp/luci-theme-rgb-ultra_1.0.0_all.ipk && opkg install /tmp/luci-theme-rgb-ultra_1.0.0_all.ipk
